🎮 Игровые возможности










Рыбалка
- !рыбалка — поймать рыбу.
- !рыба и !fish — альтернативные команды.
- 15 секунд между попытками.
- Обычная, редкая и легендарная рыба.













Экономика
- !баланс — проверить монеты.
- !ежедневно — получить 100 монет раз в день.
- !магазин — посмотреть удочки.
- !купить улучшенная — купить улучшенную удочку за 500 монет.
- !купить золотая — купить золотую удочку за 1500 монет.













Профили и уровни
- !профиль — статистика игрока.
- Опыт XP за пойманную рыбу.
- Повышение уровня.
- Учёт монет, улова и редкой рыбы.













Рейтинги
- !топ — ТОП-5 богачей.
- !топрыбаки — ТОП-5 рыбаков.
